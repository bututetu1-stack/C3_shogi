# C3将棋 第8版 計画（部員が育つローグライクへ）

## Context（背景）
ユーザーから次の指摘があった（2026-10-11）。
- レアリティが意味を為していない
- 敵の局の強化に、味方の強さが追いついていない
- 物鉄だけ凝りすぎなので、ほかの部員も凝りたい（三段階成りなど何でもあり）
- 「改良案を死ぬ気で考えて。協力できることはやる」

自動プレイ（`BalanceReports/v9`、通常100周）で測ると、原因は1つにまとまる。部員が対局のあいだ育たない。
- **局ごとの上乗せ**: 第十五局で、敵は体力+7・攻撃+3・敵C3+7。味方は体力+3・防御+2で、攻撃は+0（`StageManager.ScaleEnemy` / `ScalePlayer`）。
- **局ごとの勝率**: ほぼ8〜9割だが、第四局82%・第六局84%・第十四局82%・第十五局50%。全クリアは16%。
- **味方の攻撃に上乗せを付けた試し**（`PlayerAtkDivisor=5`）: 平均 9.16局 → 10.58局、全クリア 16% → 24%。数値を足すだけでも追いつくが、育つ手応えはない。
- **レアリティ**: 15局で仲間を16回選ぶのに部員は11人で、最後にはほぼ全員そろう。激レアが5人いて、第十局では1枠の約4割が激レア。

### ユーザーが決めたこと
- 難しさの目安: 強い AI が指したときの全クリアを **20〜35%** にする（いまは16%）。
- 覚醒は **対局中にその場で**: 練度★3の部員が、その局で活躍を3回重ねると、カットインとともに覚醒する。
- きぷは **レアに戻す**。激レアは SN・ユウ・李白の3人。
- 核のほかに次の4つも入れる。
  - 敵ボスの覚醒
  - 中断して続きから
  - AI を能力に強く
  - 局の合間のできごと

### いつもの約束
- 返答は日本語。人物の絵は使わない。セリフは増やさない（差はカットイン・エフェクト・駒の見た目で付ける）。
- バランスは自動プレイで前後を測る。確認は短く（60〜100周、10分を超えるなら裏で回す）。
- マージはユーザーの指示があったときだけ。

## Phase 1: 練度（`feat/growth`）
部員は周のあいだ「練度」をためて★が付く。★3で覚醒が解禁される（覚醒そのものは Phase 2）。

**新規 `Assets/Scripts/Roguelike/RunRoster.cs`**
- 部員ごとに `{ PieceType, 練度, 星, この局の活躍 }` を持つ。
- `GameManager.playerOwnedPieces`（`List<PieceData>`）と並べて持つ。セーブ（Phase 5）でもそのまま使う。

**練度のたまり方**（数値は自動プレイで合わせる）
- 敵を倒す: +1。誰が倒したかは `GameSim` の attacker / `AbilitySource` で分かる。`GameSim.CurrentKiller()` として公開し、`CombatResolver.KillPiece` から `RunRoster.OnKill` を呼ぶ。
- 局を生き残る: +1。`StageClearSequence` のときに盤にいる部員。
- 能力が決まる（「活躍」、1局に+2まで）: 次の場所で `RunRoster.OnFeat(piece)` を呼ぶ。
  - 僕: 強化が入った（`ProcessBokuBuffs`）
  - ヲツ: 中華が食べられた（`HealAdjacentAllies` の feed。中華に作り手 `summoner` を持たせる）
  - けい: 数値を下げた（`ExecuteKeiAbility`）
  - きぷ: 冷笑した（`ExecuteKipuAbility`）
  - 李白: 裏返した（`ExecuteRihakuAbility`）
  - 小錦: 攻撃を受け止めた（`Sympathize`）
  - なこ: 突撃が当たった（`NakoAbilityBody`）
  - 物鉄: 作戦完了（`CheckLinkedDeaths`）

**★の段階**
- レアリティごとに必要な練度を変える（大器晩成）。

  | レアリティ | ★1 | ★2 | ★3 |
  |---|---|---|---|
  | ブロンズ | 3 | 6 | 10 |
  | レア | 4 | 8 | 13 |
  | 激レア | 5 | 10 | 16 |

- 効果: ★1で攻撃+1、★2で体力+2、★3で覚醒解禁と防御+1。
- 局の初めに `GameManager.ApplyRunBonus` で付ける（全軍強化と同じ流れ）。
- 物鉄の★3は「着任した艦娘が最初から改」にする。

**鍛える札**（`PiecePool.DrawOptions` / `DraftOption` に種類を足す）
- 「〇〇を鍛える（練度+3）」。第三局から1枠混ざる。部員がそろってくると、新しい部員の枠も鍛える札で埋める。
- 激レアの部員ほど出にくくする。

**画面**
- `PieceRenderer`: 自軍の部員の空いている角（駒から見て左下）に★を出す。
- `PieceDetailUI`: 「練度 7/8 ★1」のゲージを出す。
- `PieceSelectionUI`: 鍛える札に、その部員の駒と練度を出す。
- `GameOverUI`: 部員ごとの★・練度・撃破数と、周の MVP を出す。

**自動プレイ**
- `SimStageRecord` に部員ごとの★と練度を記録する。
- `docs/balance/aggregate.js` に「何局目で★3に届いたか」を足す。

## Phase 2: 覚醒の仕組みと最初の3人（`feat/awakening`）

**仕組み**
- `PieceData` に足すもの:
  - `canAwaken`、`awakenedName`、`awakenedDescription`
  - `awakenedATK/DEF/HP`（上乗せ）、`awakenedMoveDirections`（空なら今の動き）
  - `awakenCaption`（カットインの副題。台詞ではなく、提督の「全艦隊、抜錨せよ！」と同じ扱い）
- `PieceInstance` に `awakened` と `awakenCharge`（その局の活躍の数）を足す。
- ★3の部員の活躍が3回たまると、`GameManager.AwakenRoutine` が走る。
  - `CutInUI.Play`（部員ごとの色で）
  - 裏返しの演出（`CombatResolver.PlayFlip` の流れ）と覚醒の光柱
  - 数値の反映とログ
- 覚醒は成りとは別の状態で、成っていてもいなくても付く。小錦・SN の「成ると退場」には触れない。
- 見た目: `PieceSkin` に覚醒の姿（漆に金と紫の縁・強い光・★3の印）を足す。`SpriteFactory.SpecialBody("awakened")`。
- 駒の情報・駒一覧で覚醒した姿を見られるようにする（物鉄・改と同じ作り）。

**最初の3人**（数値は仮。自動プレイで目安に合わせる）
- **小錦「横綱」**: 防御+1・体力+4。
  - 手番の終わりに、組み止めている敵1体を押し出す。小錦から離れる向きに1マス押して2ダメージ（防御無視）。押した先がふさがっていれば押さずに4ダメージ。
  - 演出は土俵の円と塩まき。
- **僕「後方腕組の極み」**: 攻撃+1・体力+2。
  - 周り2マスの味方を毎手番強化する（待ちなし、攻撃と防御の低いほう、1体+4まで）。
  - 1局に1回、隣の味方が倒されるときに身代わりになる（`CombatResolver.ApplyDamage` / `ResolveMove` で受け先を差し替える）。
- **けい「デバッグ完了」**:
  - 異端の効果（3体×2）に加えて、周りの敵を「封印」する。`PieceInstance.sealed` を立て、その局のあいだ能力が止まる。
  - 止まる能力: 魔王の雷撃・閻魔の回復・軍将の強化・黄泉の召喚・髑髏の自爆・深海の攻撃。`AbilitySystem` のそれぞれのループで `sealed` を飛ばす。

**自動プレイ**: `SimOptions.awakenAtStart`（強制した部員を局の初めから覚醒させる）で、覚醒した姿の強さを部員ごとに測る。

## Phase 3: 残りの部員の覚醒と再行動（`feat/awakening-2`）
**再行動の仕組み**: 倒したらもう1回動ける。
- `GameManager` に `bonusMovePiece` を持たせ、その駒だけ選べる状態で手番を続ける。
- `InputManager` は選べる駒を絞る。AI と自動プレイは、その駒だけで `TryChooseMove` する。

**部員ごとの覚醒**
| 部員 | 覚醒 | 効果 |
|---|---|---|
| ヲツ | 満漢全席 | 中華4つを2マス先まで届ける。満腹は1体2回まで。覚醒した手番に全員を1回復 |
| なこ | ドパ・オーバードライブ | 突撃で倒すと、もう一度突撃（2回まで） |
| 門人 | 免許皆伝 | 絶起しなくなる。倒したら自動でもう1回動く |
| きぷ | 絶対零度 | 冷笑が2マス先・3体まで届く。冷笑された敵は凍って防御−1 |
| 李白 | 詩仙 | 裏返しが賢くなる（味方は成ると得な駒だけ成らせ、敵は成り駒だけ戻す）。裏返すたびに攻撃+1（3まで） |
| ユウ | ゾーン | 助走で倒すと再行動 |

- **SN**: 覚醒なし（先代部長なので強いまま）。★は付く。退場のときに専用カットインと後光の演出。
- **物鉄**: ★3で艦娘が改から始まる（Phase 1）。

## Phase 4: 敵ボスの覚醒と AI（`feat/bosses-ai`）

**ボスの覚醒**（体力が半分を切った最初のとき。赤いカットイン。覚醒の見た目は部員と同じ仕組みを使う）
- 雷帝「天雷」: 攻撃+1。敵の手番の終わりに、縦横の線上の自軍1体へ落雷2。
- 龍神「昇龍」: 体力を半分まで回復（1回）。斜めも2から無限になる。
- 魔王「真・魔王」: 雷撃が2体に。攻撃+2。魔王の局の BGM を変える差し込み口（`BGM_Boss`）。

**AI を能力に強く**（`SimpleAI.PieceValue` / `Evaluate`）
- 敵側（ゲームの AI）:
  - 支援役の駒の値打ちを上げる: 自軍のヲツ・僕・けい・きぷ・李白、敵の閻魔・軍将・黄泉。これで優先して狙い、自分の支援役は守るようになる。
  - 中華を倒す価値を入れる。
- 自軍側（自動プレイ）:
  - 僕のそばに味方を置く。
  - 中華に隣接する。
  - 小錦を敵の前線に寄せる（組み止める敵の数）。
  - けい・きぷは手番の終わりに敵の隣にいる。
- 探索の時間（150ms）は守る。変えたあとは通常の周を測り直す（AI が変わると基準が動くため）。

**難しさの調整**: 最後に通常300周で全クリア 20〜35% に合わせる。
- 調整する値: 練度の量、★の効果、敵の上乗せ（`EnemyHpDivisor` など）。
- 第四局・第六局の山（82%・84%）もならす。

## Phase 5: 周の流れ（`feat/run-flow`）

**局の合間のできごと**（新規 `UI/StageEventUI.cs`）
- 局に勝ったあと、仲間選びの前に、2つのできごとから1つを選ぶ（第二〜十四局）。
- できごとの例:
  - 部室で休む: C3の体力+2（周のあいだ）
  - 練習試合: 選んだ部員の練度+2
  - 合宿: 全員の練度+1
  - 部費: 引き直し+2
  - 強敵に挑む: 次の局は敵の体力+1、代わりに仲間を2枚選べる
- 絵は使わず、文字と駒のアイコンだけで見せる。
- 自動プレイではランダムに選ぶ。

**中断して続きから**（新規 `Roguelike/RunSave.cs`）
- 保存の時点: 仲間選びを終えて対局を始める直前と、局に勝った直後。
- 保存するもの:
  - 局、部員と練度（`RunRoster`）
  - 全軍強化、応急修理要員、S勝利のごほうび
  - 引き直しの残り
- 形式は JsonUtility で `Application.persistentDataPath/run.json`。
- タイトル画面に「続きから」を出す（保存があるときだけ）。負けたとき・全クリアしたときは消す。
- 対局の途中でやめたときは、その局の初めからやり直す。

**遊び方・駒一覧**: 練度・覚醒・組み止め・できごとを書き足す。駒一覧で覚醒した姿を見られるようにする。

## 確かめ方（各段階で）
- **コンパイルとテスト**: `isuzu-unity-cli verify --test --filter '.'`。テストを足す。
  - 練度の★の閾値
  - 覚醒の発動（活躍3回）
  - 押し出しの行き先
  - 封印で能力が止まる
  - 再行動
  - セーブして読み直す
- **自動プレイ**:
  - 段階ごとに、通常100周と、変えた部員の強制80周。
  - 最後に通常300周と部員ごとの80周で、全クリア20〜35%、部員の目安（ブロンズ ≦ レア ≦ 激レア、提督 +2〜+3）を確かめる。
  - 艦隊は `fleet_stats.js` で確かめる。
- **画面**: プレイモードで、それぞれ RenderTexture で撮って確かめる。
  - 覚醒のカットイン・★・鍛える札
  - できごとの画面
  - 続きから（タイトル → 再開）
  - ボスの覚醒
- **ユーザーの試遊**: 段階ごとに1周遊んでもらい、感想を次の段階に反映する。
