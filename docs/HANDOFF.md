## 自動プレイの並列化（2026-10-10）
- エディタで1本ずつ回すと本番（通常300周＋駒ごと100周×15）が3〜4時間かかったので、画面なしの専用ビルドを並列に回す形にした（手順は CLAUDE.md）。
- ノート PC（論理22コア）で10〜14本同時に回すと、エディタの4〜5倍の速さ。1本あたりはエディタの約2倍遅くなる（CPU の取り合い）が、AI の読みの深さはほぼ変わらない（4手先まで読めた手: 敵73% / 自軍97%）。
- ビルドすると URP の設定（`Assets/Settings/UniversalRP.asset` など）や ProjectSettings に差分が出る。ビルドのたびに Unity が書き換えるものなので、コミットしない。
- ノート PC のエディタは、開いた直後はシーンが開かれていない。エディタで自動プレイを回すときは `Assets/Scenes/SampleScene.unity` を開いてからプレイする。

## けい・能力の強化（feat/kei、2026-10-10）
- けい（レア、攻1・防1・体2、斜め1マス）→ 異端（攻2・防1・体3、斜め2マス）。自分の手番の終わりに、周囲1マスの敵の数値（攻撃・防御・体力）をランダムに1つ下げる（異端は2つ）。攻撃・防御は0未満にせず、体力は最大と現在を下げて1は残す。C3 は対象外。セリフ「それはバグやろ！」「バグ多すぎやろ！」、成るとカットイン「けい 異端化」。データは `Assets/Resources/Pieces/Kei.asset`。
- ユーザーと決めたこと: けいも異端も敵だけが対象／発動は自分の手番の終わりに毎回／能力による攻撃すべて（なこ・深海・艦娘・魔王の雷撃・髑髏の爆発）に攻撃の上乗せを足す／異端の動きは斜め2マス。
- 能力のダメージ = 基本の値 + 出どころの駒の攻撃の上乗せ（最低1）。対局の途中で出る駒（深海・艦娘・黄泉の歩）にも、その局のほかの駒と同じ強化を付けるようにした。
- 艦娘の動き: 縦横斜め1マス → 3マス（飛び越えなし）。
- 自動プレイ（通常300周、第2版との比較）: 平均7.06局で同じ、全クリア 3周 → 0周。第十三局 75% → 58%、第十五局 11% → 0%（魔王の雷撃が毎ターン貫通4になり、1局で4.8体倒す）。提督（毎局最初から）+2.38局 → +4.79局。けい −0.10局（レアの目安 +1局より弱め）。
