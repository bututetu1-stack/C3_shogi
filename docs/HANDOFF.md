## ノート PC での準備
1. Unity Hub で Unity **6000.3.3f1** を入れる。
2. `git clone https://github.com/bututetu1-stack/C3_shogi` して、作業ブランチ（下の表）を checkout する。
3. git のローカル設定: `git config core.autocrlf false` と `git config core.eol lf`。
4. Unity でプロジェクトを開く（初回は Library の生成に時間がかかる）。
5. Claude にエディタを操作させるなら、`isuzu-unity-cli` を入れてエディタとつなぐ。
6. バランステストの集計には Node.js を使う（`node --version` で確認）。
