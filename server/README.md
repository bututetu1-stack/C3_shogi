# 対人戦の中継サーバー

オンラインの対人戦で、2人のゲームのあいだの手を中継するだけの小さなサーバーです。
Cloudflare Workers の無料の枠に置きます。ミニPCは使わず、ポート開放も要りません。遊ぶ人は何も入れなくてかまいません。

- `worker.js`: Cloudflare に置くサーバー（部屋ごとに Durable Object を1つ使う）
- `wrangler.toml`: 置くときの設定
- `local-relay.js`: 手元で試すための、同じ働きをする Node のサーバー（追加の部品は要らない）
- `test-bot.js`: 通信を試すための相手役（部屋を作り、決まった編成で、1手指したあとはパスする）

## 置き方（初めの1回だけ）

1. Cloudflare のアカウントを作ります（無料）: https://dash.cloudflare.com/sign-up
2. Node.js が入っている PC で、このフォルダ（`server`）を開き、次の2つを順に打ちます。
   - `npx wrangler login`: ブラウザが開くので、Cloudflare にログインして許可します。
   - `npx wrangler deploy`: サーバーを置きます。
   - `npx` は、Cloudflare の公式の道具 wrangler を、その場で取ってきて動かします。
3. 終わると `https://c3shogi-relay.〇〇.workers.dev` のようなアドレスが出ます。ブラウザで開いて「動いています」と出れば成功です。
4. ゲームの「対人戦」の画面の「オンラインのサーバー」に、そのアドレスを入れます。
   - `https://` で始まるままでかまいません（ゲームが `wss://` に直します）。
   - 一度入れれば次からは覚えています。
   - 相手にもこのアドレスを教えてください。

## 遊び方

- 部屋を作る人: 「対人戦 → 部屋を作る」でルールを選びます。4桁の部屋コードが出るので、相手に伝えます。
- 入る人: 「対人戦 → 部屋に入る」で、その部屋コードを入れます。
- 先手と後手は、相手が入ったときにランダムで決まります。後手の人の画面では、盤が180度回って自分の駒が手前に来ます。
- 通信が切れても、同じ画面のまま自動でつなぎ直します。サーバーが手の記録を持っているので、続きから指せます。

## 手元で試す

```
node server/local-relay.js 8787
node server/test-bot.js ws://localhost:8787 4321
```

ゲームの「オンラインのサーバー」に `ws://localhost:8787` を入れて、「部屋に入る」で `4321` に入ります。相手役（test-bot）が先手になります。

## しくみ

- サーバーはゲームの中身を知りません。届いた手をもう1人に送り、記録に残すだけです。
- 2人のゲームは、同じ乱数の種（`GameRng`）で、同じ手を同じ順番に再生します。そのため同じ盤になります。
- 手番が変わるたびに、盤の要約を送り合います。食い違ったら、対局記録に「※ 盤が食い違っている」と出ます。
- 部屋は、6時間さわられなければ片付けます。
